# Documentation

The BATHRON documentation is **not** maintained in this repository. It has a single
canonical source, rendered automatically as an mdBook.

- **Read it:** <https://bathron.org/docs/> — start with <https://bathron.org/docs/overview.html>
- **Source (edit here):** <https://github.com/bathron-network/bathron-network.github.io/tree/main/docs/src>
- **Network status:** <https://bathron.org/docs/status.html>
- **Known limitations:** <https://bathron.org/docs/limitations.html>
- **Documentation policy:** [Editorial style](https://github.com/bathron-network/bathron-network.github.io/blob/main/docs/STYLE.md)

Please do not add conceptual documentation to this repository — open a pull request against
the documentation source above instead, so there is exactly one canonical page per topic.

Security policy and vulnerability reporting live in [`../SECURITY.md`](../SECURITY.md).
